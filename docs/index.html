E2E-шифрование в браузере

ECDH P-256 для обмена ключами, AES-GCM-256 для сообщений. Приватный ключ хранится в IndexedDB как non-extractable и не покидает устройство.

02

Файлы на сервере компании

Один VPS в российском дата-центре, PostgreSQL и Redis локально. Никаких облачных сервисов. Требование о локализации по ФЗ-242 закрывается автоматически.

03

Автопарсинг документов

ИНН, КПП, ОГРН, БИК, расчётные счета, суммы и даты извлекаются из PDF, DOCX и XLSX. Проверка контрольных сумм по алгоритму ФНС.

Парсинг документов

Что происходит, когда сотрудник прикрепляет PDF

Парсинг запускается автоматически в момент загрузки. Получателю не нужно нажимать ничего, чтобы увидеть реквизиты.

  1. Файл уходит в микросервис

    Python 3.11 + FastAPI. PyMuPDF для PDF, python-docx и openpyxl для офисных форматов.

  2. Извлечение текста и структуры

    Заголовки, абзацы, таблицы и метаданные собираются в единый DocumentStructure.

  3. Распознавание реквизитов

    Регулярные выражения с проверкой контрольных сумм ФНС. Мусор и случайные числа отсеиваются.

  4. Превью в карточке сообщения

    Тип документа, номер, дата, сумма и идентификаторы появляются под файлом сразу у обоих собеседников.
