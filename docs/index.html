Что внутри

🔐

Сквозное шифрование

ECDH P-256 для обмена ключами, AES-GCM-256 для шифрования сообщений. Приватный ключ хранится только на устройстве пользователя в IndexedDB (non-extractable). Сервер общим ключом пары не располагает.

📄

Парсинг деловых документов

Автоматическое извлечение реквизитов из PDF, DOCX, XLSX, TXT: ИНН (с проверкой контрольных сумм ФНС), КПП, ОГРН, БИК, расчётные счета, денежные суммы, даты, номера договоров. Превью реквизитов прямо в карточке сообщения.

🏢

On-premise развёртывание

Полный контроль над данными. Один VPS — 2 vCPU, 4 ГБ RAM, 40 ГБ SSD — обслуживает до 500 одновременных WebSocket-подключений. Соответствие требованиям ФЗ-152, ФЗ-242, ФЗ-149.

⚖️

Соответствие законодательству

Локализация ПД на территории РФ (ФЗ-242). Поддерживается переход на отечественную криптографию (ГОСТ «Кузнечик» через КриптоПро CSP) в следующих версиях. Журнал аудита для расследования инцидентов.

⚡

Реальное время

WebSocket-обмен сообщениями с p99-латентностью 38 мс. Обмен файлами до 50 МБ, голосовые сообщения, статусы прочтения, ответы на сообщения, форматирование текста.

📂

Открытый исходный код

Лицензия MIT. Возможен независимый аудит безопасности. Подходит для адаптации под индивидуальные требования малого и среднего бизнеса.
